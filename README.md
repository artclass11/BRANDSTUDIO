## Hosting
This is a static site with no build step and no third-party runtime dependencies. It can be hosted on GitHub Pages or a static hosting provider.

For GitHub Pages, open **Settings → Pages** and configure the repository to deploy from **GitHub Actions** (the required one-time settings step when Pages is not yet enabled). The site workflow, when present, should use the `github-pages` environment and the official Pages deployment actions.
